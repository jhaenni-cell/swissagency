# Swiss Clips — Clipping Agency Website

Static one-page website (HTML/CSS/JS, no build step).

- `index.html` – content & structure
- `styles.css` – design (clean white, minimal, responsive)
- `script.js` – mobile nav, scroll reveal, contact form (opens mailto; set `CONTACT_EMAIL`)

Open `index.html` in a browser, or deploy the folder to Netlify / Vercel / GitHub Pages.
